# 02 特性清单

> 目标：一页看全控件支持的所有特性（Attribute），包含标准 .NET 特性与 `PropertyGridLib.Attributes` 下的 8 个自定义特性，每个特性都能直接照抄代码。

---

## 一、总览

| 特性 | 命名空间 | 适用属性类型 | 作用 |
|------|---------|-------------|------|
| `[Category]` | `System.ComponentModel` | 任意 | 属性分组（分类标题） |
| `[DisplayName]` | `System.ComponentModel` | 任意 | 自定义显示名 |
| `[Description]` | `System.ComponentModel` | 任意 | 底部描述栏文本 |
| `[DefaultValue]` | `System.ComponentModel` | 任意 | 默认值，控制复位按钮显示 |
| `[ReadOnly]` | `System.ComponentModel` | 任意 | 只读（编辑器禁用） |
| `[Browsable(false)]` | `System.ComponentModel` | 任意 | 隐藏该属性行 |
| `[FilePath]` | `PropertyGridLib.Attributes` | `string` | 文件路径选择（文本框 + 浏览按钮） |
| `[DirectoryPath]` | `PropertyGridLib.Attributes` | `string` | 目录路径选择（纯 WPF 目录对话框） |
| `[CollectionEditor]` | `PropertyGridLib.Attributes` | `IList` | 集合编辑器对话框（简单/复杂对象自适应） |
| `[NumberSlider]` | `PropertyGridLib.Attributes` | 数值类型 | 滑块编辑器（可选数字框） |
| `[FormulaEditor]` | `PropertyGridLib.Attributes` | `FormulaBound<T>` | 公式绑定区 + 公式树选择器 |
| `[MultiSelect]` | `PropertyGridLib.Attributes` | `List<string>` | 多选列表（CheckBox 弹窗） |
| `[Button]` | `PropertyGridLib.Attributes` | `object` / `string` | 命令按钮 + 反射调用宿主方法 |
| `[ToggleSwitch]` | `PropertyGridLib.Attributes` | `bool` | 布尔开关（滑块开关 + 可定制状态文字） |

> 多个特性可叠加使用，例如 `[Category]` + `[DisplayName]` + `[DefaultValue]` + `[ReadOnly]` 的组合最常见。

## 三、文件与目录路径

### FilePathAttribute — 文件路径选择

标记属性为文件路径，显示浏览按钮，点击弹出文件选择对话框，支持多后缀筛选。

```csharp
using PropertyGridLib.Attributes;

[FilePath("*.log")]                              // 单后缀
public string LogFilePath { get; set; } = "";

[FilePath("*.json", "*.xml", "*.txt")]           // 多后缀
public string ConfigFilePath { get; set; } = "";
```

| 成员 | 类型 | 说明 |
|------|------|------|
| `Filters` | `string[]` | 文件后缀列表（构造函数参数） |
| `Filter` | `string` | 完整过滤器字符串（如 `"*.json;*.xml"`） |
| `InitialDirectory` | `string` | 初始目录 |
| `Title` | `string` | 对话框标题 |
| `Multiselect` | `bool` | 是否允许多选 |

### DirectoryPathAttribute — 目录路径选择

```csharp
[DirectoryPath]
public string DataDirectory { get; set; } = "";
```

| 成员 | 类型 | 说明 |
|------|------|------|
| `InitialDirectory` | `string` | 初始目录 |
| `Title` | `string` | 对话框标题 |

特点：树形目录浏览、支持路径直接输入、自动跟随 HandyControl 深/浅主题、完整中英文多语言。

## 四、集合编辑器 CollectionEditorAttribute

标记集合类型属性使用编辑器对话框；简单类型（`string`、`int` 等）走简易编辑器，复杂对象走完整编辑器（含属性面板），**无需手动指定**。

```csharp
// 简单类型集合 — 输入框 + 列表 + 增删排序
[CollectionEditor]
public List<string> Tags { get; set; } = new List<string> { "A", "B" };

// 复杂对象集合 — 列表 + 属性面板 + 增删复制排序
[CollectionEditor]
public List<CameraChannel> Channels { get; set; } = new List<CameraChannel>();
```

| 成员 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `CanAdd` | `bool` | `true` | 是否允许添加新项 |
| `CanRemove` | `bool` | `true` | 是否允许删除项 |
| `CanCopy` | `bool` | `true` | 是否允许复制项 |
| `CanSort` | `bool` | `true` | 是否允许上移/下移排序 |

> `SelectedObject` 直接传入 `IList` 时也会进入内联集合编辑模式，此时无需该特性。

## 五、数值滑块 NumberSliderAttribute

将数值属性显示为滑块编辑器，支持 `int`、`double`、`float`、`decimal` 等数值类型。

```csharp
[NumberSlider(0, 100, 5)]                        // min, max, step
public int Volume { get; set; } = 50;

[NumberSlider(0.0, 1.0, 0.1)]                    // 默认显示只读数值标签
public double Brightness { get; set; } = 0.8;

[NumberSlider(0, 100, 5, ShowNumberBox = true)]  // 滑块 + 可编辑数字框，双向同步
public double Opacity { get; set; } = 50;
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `minimum` | `double` | 最小值 |
| `maximum` | `double` | 最大值 |
| `step` | `double` | 步长（默认 1） |
| `ShowNumberBox` | `bool` | 是否显示可编辑数字输入框（默认 `false`；启用后与滑块双向同步并取代只读数值标签） |

## 六、公式绑定 FormulaEditorAttribute

标记属性后，属性编辑器下方额外显示一行公式绑定区（链接图标 + 公式文本框 + Popup 树选择器）。

```csharp
[FormulaEditor(typeof(MyFormulaTreeProvider))]
public FormulaBound<string> NameFormula { get; set; } = new FormulaBound<string> { Value = "默认值" };
```

需要实现 `IFormulaTreeProvider`（`GetFormulaTree(PropertyItem)` 返回 `List<FormulaTreeNode>`），详细写法与截图见 [05 公式绑定](05-公式绑定.md)。

## 七、多选列表 MultiSelectAttribute

标记属性为多选列表编辑器，点击弹出 CheckBox 列表；属性类型应为 `List<string>`，选项由 Provider 动态返回。

```csharp
[MultiSelect(typeof(MyMultiSelectProvider))]
public List<string> SelectedOptions { get; set; } = new List<string>();
```

```csharp
public class MyMultiSelectProvider : IMultiSelectProvider
{
    public List<string> GetAvailableItems(PropertyItem propertyItem)
        => new List<string> { "选项A", "选项B", "选项C", "选项D" };
}
```

## 八、命令按钮 ButtonAttribute

被标记的属性不再显示值编辑器，而是渲染为一个按钮；点击后：① 反射调用宿主对象上 `Action` 指定的方法（若指定）；② 触发 `PropertyItem.ButtonClicked` 与 `PropertyGrid.ButtonClicked` / 静态 `PropertyGrid.GlobalButtonClicked` 事件。

```csharp
// 仅触发事件（文本回退到 DisplayName，随多语言切换）
[Button]
public object GreetButton { get; set; }

// 指定按钮文本 + 点击时反射调用的宿主方法
[Category("操作")]
[DisplayName("测试连接")]
[Button("测试连接", nameof(TestConnection))]
public object TestConnectionButton { get; set; }

public void TestConnection() { /* 点击后由库反射调用 */ }
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | `string` | 按钮文本；为空时回退到 `DisplayName` |
| `action` | `string` | 点击时反射调用的宿主方法名（无参或单参）；为空时仅触发事件 |

宿主机统一响应（推荐订阅静态全局事件，可捕获集合/字典内嵌网格中的按钮）：

```csharp
PropertyGrid.GlobalButtonClicked += (s, e) =>
{
    Console.WriteLine($"{e.PropertyName} 被点击");
};
```

> 建议将按钮属性声明为 `object` / `string` 占位类型（值可为 null）。按钮默认始终可点，仅当属性显式标注 `[ReadOnly(true)]` 时禁用。

## 九、布尔开关 ToggleSwitchAttribute（1.3.0 新增）

标注在 `bool` 属性上时，属性行的编辑器渲染为「**滑块式开关**（圆角轨道 + 圆形滑块）+ 开/关状态文字」；**未标注的 `bool` 属性保持默认外观**（同为滑块开关，但不带状态文字）。该特性**仅对 `bool` 生效**，标注在其它类型属性上会被忽略。

```csharp
using PropertyGridLib.Attributes;

[Category("开关")]
[DisplayName("启用记录回放")]
[ToggleSwitch]                                     // 默认状态文字「开 / 关」
public bool LoopRecording { get; set; }

[ToggleSwitch("已启用", "已禁用")]                  // 自定义状态文字
public bool UseHttps { get; set; }

[ToggleSwitch(OnText = null, OffText = null)]       // 只显示开关，不显示文字
public bool IsEnabled { get; set; }
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `onText` | `string` | 打开（`true`）状态文字，默认「开」；为 `null` 或空字符串表示不显示文字 |
| `offText` | `string` | 关闭（`false`）状态文字，默认「关」；为 `null` 或空字符串表示不显示文字 |

两个参数也可作为命名参数单独设置，例如 `[ToggleSwitch(OnText = "在线")]`。

| 未标注（默认 bool） | 标注 `[ToggleSwitch]` | 自定义文字 `[ToggleSwitch("已启用","已禁用")]` |

## 十、优先级与自定义

1. **宿主自定义编辑器优先**：通过 `PropertyGrid.RegisterEditor<TAttribute>(template)` / `CustomEditors` 注册的模板会覆盖框架内置编辑器的渲染路径（详见 [03 编辑器类型总览](03-编辑器类型总览.md)）。
2. **特性优先于类型**：如 `[NumberSlider]`（滑块）优先于普通的数值输入框，`[ToggleSwitch]`（带文字开关）优先于默认 bool 开关。
3. **冲突时的取舍**：同一属性同时标注 `[ReadOnly(true)]` 与编辑器类特性时，编辑器仍会渲染，但处于禁用态。
